# Mamal joone — نسخه‌ی اولیه

نسخه‌ی MVP با Expo / React Native: بوم نقاشی دستی، رنگ‌ها، اندازه‌ی قلم، پاک‌کن، undo/redo، ذخیره‌ی اثر به شکل SVG، حساب کاربری Supabase و فهرست گالری آنلاین.

## پیش‌نیازها
- Node.js نسخه‌ی LTS
- اپ Expo Go روی گوشی برای آزمایش سریع
- پروژه‌ی رایگان Supabase برای ورود و گالری آنلاین

## اجرا
1. فایل zip را استخراج کن و در پوشه‌ی پروژه ترمینال باز کن.
2. وابستگی‌ها را نصب کن:
   ```bash
   npm install
   ```
3. از `.env.example` یک کپی با نام `.env` بساز و مقادیر پروژه‌ی Supabase را قرار بده:
   ```env
   EXPO_PUBLIC_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
   EXPO_PUBLIC_SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_KEY
   ```
4. در Supabase، بخش SQL Editor را باز کن و محتوای `supabase.sql` را اجرا کن.
5. برای تست روی گوشی:
   ```bash
   npx expo start
   ```
   اسکن QR code با Expo Go. برای iOS و Android، گوشی و کامپیوتر معمولاً باید روی یک شبکه باشند.

## راه‌اندازی Supabase
- از Supabase Dashboard یک پروژه بساز.
- URL و anon/publishable key پروژه را از Project Settings > API بردار.
- در Authentication > Providers، Email را فعال کن.
- برای تست ثبت‌نام، تنظیمات تأیید ایمیل را طبق نیاز پروژه تنظیم کن. در حالت تأیید ایمیل، کاربر باید لینک ایمیل را باز کند.
- SQL موجود در `supabase.sql` جدول `artworks`، سیاست‌های RLS و bucket عمومی `artworks` را می‌سازد.

## امکانات فعلی
- رابط فارسی راست‌چین
- طراحی دستی با لمس/ماوس
- پالت رنگ، اندازه‌ی قلم و پاک‌کن
- Undo / Redo و پاک کردن بوم
- ثبت‌نام و ورود با ایمیل و رمز عبور
- آپلود SVG و ثبت اثر در گالری آنلاین

## محدودیت‌های نسخه‌ی اولیه
- فعلاً لایه‌های مستقل، انتخاب/جابجایی عناصر، براش‌های بافت‌دار، خروجی PNG و ابزار کلاژ پیاده‌سازی نشده‌اند.
- گالری در این MVP فهرست متادیتا و لینک اثر را نشان می‌دهد؛ نمایش بندانگشتی SVG را می‌توان در گام بعد اضافه کرد.
- پیش از انتشار عمومی، باید صفحه‌بندی گالری، گزارش/مدیریت محتوا، حذف امن اثر، بازیابی رمز عبور، سیاست حریم خصوصی و تست امنیتی اضافه شود.
- کلید `service_role` را هرگز داخل اپ یا فایل `.env` کلاینت قرار نده؛ فقط anon/publishable key برای اپ.
- برای ساخت فایل نصب نهایی از EAS Build استفاده کن؛ این پروژه در حال حاضر یک کدبیس Expo است، نه فایل APK/IPA آماده.
